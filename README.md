# Piyusha & Swapnil Engagement Invitation (bride's side)

A single-page digital invitation for the engagement ceremony on Thursday, 19 November 2026 at Hotel Comfort Inn & Banquet Hall, Pachrukhi, Siwan, Bihar.

This is the bride's-side version: Piyusha's name and parents come first, followed by Swapnil's, with each set of parents shown directly under the name.

It includes a welcome popup, soft piano music generated in the browser, a countdown, the day's schedule, WhatsApp RSVP buttons, and links for directions and adding the event to Google Calendar.

## Viewing it

Open `index.html` in any browser. It needs no build step and no server.

## Editing details

Names, parents, schedule and venue are in the HTML. The event time, calendar title, venue for maps, WhatsApp numbers and RSVP message are in the `INVITE` object near the top of the `<script>` block.
